## Introduction

For years, developers relied on heavyweight CSS utility frameworks to achieve consistency and maintainable responsive designs. However, CSS has undergone a renaissance: CSS custom properties (variables), native container queries, cascade layers (`@layer`), and `subgrid` now provide immense power natively without runtime baggage.

In this guide, we will look at how to build an ultra-clean, modular CSS design system.

## Designing with Semantic CSS Variables

Modern tokens can be grouped logically by purpose, with automatic light and dark mode switching via `[data-theme]` attributes:

```css
:root {
  --bg-primary: #ffffff;
  --bg-surface: #f8fafc;
  --text-main: #0f172a;
  --accent: #4f46e5;
  --radius-card: 16px;
  --shadow-soft: 0 4px 20px -2px rgba(0, 0, 0, 0.05);
}

[data-theme='dark'] {
  --bg-primary: #0b0f19;
  --bg-surface: #131b2e;
  --text-main: #f8fafc;
  --accent: #818cf8;
  --shadow-soft: 0 4px 24px -2px rgba(0, 0, 0, 0.4);
}
```

<Callout type="tip" title="Color Contrast Accessibility">
Always test your color tokens against WCAG 2.1 AA standards (minimum 4.5:1 ratio for standard text) to ensure effortless readability across both light and dark themes.
</Callout>

## The Power of CSS Subgrid

Aligning headers and footers across different cards in a dynamic grid was once notoriously tricky. `subgrid` makes it trivial:

```css
.card-grid {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(320px, 1fr));
  gap: 1.5rem;
}

.card {
  display: grid;
  grid-row: span 3;
  grid-template-rows: subgrid;
}
```

## Summary

Native CSS today delivers unmatched performance, zero dependency maintenance, and full layout control. By understanding modern primitives, you can craft designs that stay blazing fast and maintainable for years.
